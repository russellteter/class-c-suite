## The one job (the wedge)
A **personal C-suite strategic decision tool**. On demand, Russell poses a real decision he faces as
COO. The tool runs a 6-lens C-suite analysis and returns a reconciled, cited memo + recommendation —
**grounded in his live, maintained Obsidian "Business Planning" vault** plus real financial/pipeline data.

## The edge (why it beats thinking-it-yourself or ChatGPT) — Russell's words
> "Fully leveraging real-time learned knowledge, fresh decisions, date-aware documentation and files,
> from the Obsidian Vault 'Business Planning'. … always using the most up-to-date and accurate and
> relevant and context aware information to help guide decisions and form perspective and make
> recommendation. Additionally, the ability for the 'hand back to Claude Desktop CoWork' documentation
> and files and prompt is working."

The differentiator is **provable currency of context**: every analysis demonstrably pulls the most
current, relevant, date-aware content from the maintained vault — and Russell can see which vault items
and live data informed it. Generic advice is the failure mode to design against.

## Locked decisions (form)

- **Must be real (non-negotiable grounding):** live Obsidian "Business Planning" vault · cash-model xlsx

## Acceptance criteria (DRAFT — finalized after the target-scoped audit)
1. **On-demand strategic flow, live + reliable:** Russell poses an arbitrary strategic decision in the
   app → a 6-lens reconciled, Opus-verified memo ships end-to-end, repeatably (≥ the 4/4 cash bar).
2. **Provable live-vault grounding (the edge):** the analysis retrieves the *currently relevant,
   recently-updated* vault notes/docs (date-aware) and cites them; Russell can see WHICH vault items
   informed each claim. Stale or generic-without-vault output is a fail.
3. **Real data, honest:** NetSuite + Salesforce + AWS + cash model pulled live and cited, with honest
   degradation (clearly flagged) when a source is unavailable — never fabricated.
4. **Renders + hands back:** the memo (with its vault/data provenance) renders in the app, and produces
   a **Claude Desktop CoWork hand-back** (docs + files + a continuation prompt) Russell can open and run.
5. **Dogfood:** Russell runs it on one real decision this week and it materially helps — specifically
   because it surfaced current vault/data context he'd want, not generic advice.
