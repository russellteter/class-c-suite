## Confidence semantics
- **90-100:** I would bet my role on this. Reverse only with extraordinary evidence.
- **75-89:** High conviction. Counter-evidence noted; not currently outweighed.
- **60-74:** Lean. Better than coin flip but reversible.
- **40-59:** Uncertain. Held provisionally; do not cite as basis for one-way doors.
- **0-39:** Contrary view documented for completeness; not the working belief.

## Discipline

1. Every Pass 2 lens that takes a stance writes a position to `active/`.
2. Every Pass 3 red-team finding that survives modifies a position.
3. Every Pass 5 memory write that is a *belief* (not a fact) becomes a position rather than a project memory.
4. Monthly audit (first Monday): walk every active position, retest against current data, adjust confidence or supersede.
5. Superseded positions move to `superseded/` — never deleted; audit trail preserved.

`active/POS-NNN-short-slug.md` — three-digit zero-padded ID, lowercase hyphenated slug derived from the claim.
